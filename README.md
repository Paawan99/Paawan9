# Card Finder

Static GitHub Pages site for:

https://cardfinder.paawanshah99.com

The root page and `credit-card-finder.html` both serve the Canadian credit card finder. Runtime data lives in `data/credit-cards.json` and `data/bank-kb-lite.json`.

This repository is intentionally separate from the main portfolio site so the card finder subdomain can be updated without changing `paawanshah99.com`.
